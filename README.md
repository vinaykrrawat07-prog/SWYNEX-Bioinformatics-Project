# SWYNEX Technologies – Bioinformatics Project

## Biological Dataset Selection, Data Cleaning, Basic Analysis, Visualization and Interpretation

### 1. Project Overview

This project explores the use of computational tools to organize, analyze, visualize, and interpret biological data. It uses a publicly available bacterial genome dataset obtained from the National Center for Biotechnology Information (NCBI).

The project is organized into three stages: biological dataset selection, data cleaning and basic analysis, and visualization and interpretation.

### 2. Research Question

What genomic characteristics of *Lactobacillus delbrueckii* subsp. *bulgaricus* strain TCI904 can be explored using biological data analysis and visualization, and how can these characteristics contribute to our understanding of its relevance to dairy fermentation?

### 3. Dataset Information

- **Organism:** *Lactobacillus delbrueckii* subsp. *bulgaricus*
- **Strain:** TCI904
- **RefSeq Assembly:** GCF_040267765.1
- **GenBank Assembly:** GCA_040267765.1
- **BioProject:** PRJNA1123883
- **Data Source:** NCBI

**NCBI Dataset:** https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_040267765.1/

### 4. Project Tasks

#### Task 1: Biological Dataset Selection

- Identify a relevant bacterial genome dataset from NCBI.
- Document the organism, strain, assembly accession, and source.
- Establish the research question and biological background.
- Record relevant genome assembly characteristics.

#### Task 2: Data Cleaning and Basic Analysis

- Collect and organize relevant biological data.
- Inspect missing values, duplicate records, and inconsistencies.
- Validate the data against the original source.
- Perform descriptive statistical analysis where appropriate.
- Prepare a structured dataset for visualization.

#### Task 3: Visualization and Interpretation

- Create appropriate charts using Python.
- Explore genome size, GC content, and other verified genomic features.
- Compare reference strains when suitable, comparable data are available.
- Interpret each graph using evidence from the analyzed data.
- Document the results, observations, and limitations.

### 5. Tools and Technologies

- **Matplotlib:** Data visualization
- **GitHub:** Version control and project documentation

### 6. Expected Deliverables

- Dataset description and source information
- Cleaned and organized biological data
- Python analysis scripts or notebooks
- Graphs with scientific interpretations
- Final report containing methods, results, limitations, and references

### 7. Limitations

The project uses publicly available secondary data and does not claim original laboratory experiments or new genomic discoveries. Comparisons and biological interpretations will be based on verified data. Conclusions about functional performance or fermentation efficiency require additional supporting evidence.
